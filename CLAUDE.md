## Workflow obligatoire

Avant toute tâche :
1. ouvrir `.workflow/workflow-system/WORKFLOW.md` ;
2. charger `using-superpowers/SKILL.md` depuis `.claude/skills/` ;
3. exécuter `.workflow/workflow-system/procedures/00-session-preflight.md` ;
4. suivre `.workflow/workflow-system/ROUTER.md` ;
5. charger réellement les `SKILL.md` sélectionnés par la route ;
6. lire ensuite `CONTEXT.md` et les spécifications pertinentes.

Ne jamais exposer de secret. Vérifier les résultats avant de déclarer une tâche terminée.
